# Corilo 可里交互设计

v0.32 · 2026-11-10。当前业务规则见 [PRODUCT-SPEC.md](PRODUCT-SPEC.md)，模块与实际验收见 [TECHNICAL_DESIGN.md](TECHNICAL_DESIGN.md)。本轮解决整体像表单、操作零碎的问题；不能用控件存在或测试总数替代完整流程与实际画面的检查。

保留 Harness 的对话、会话、模型设置和默认工具。Corilo 增加笔记与待办入口，继续使用宿主 React 18 和 Astryx Neutral 0.7.11 静态 token，不嵌套旧应用或引入第二个 Agent／模型配置系统。参考 [Obsidian 笔记管理](https://obsidian.md/help/manage-notes)、[文件列表](https://obsidian.md/help/plugins/file-explorer)及滴答清单的[快速添加](https://help.ticktick.com/articles/7055782422935240704)、[任务详情](https://help.ticktick.com/articles/7055782408586526720)，采用常见操作结构。

## 笔记：只有一条记录路径

桌面左侧查找／浏览，右侧写作。手机先显示正文，查找时切到列表，打开结果回正文。工具栏只放新建、轻量保存状态和编辑／阅读预览，不常驻设置、恢复或保存表单。不展示按路径打开、列表刷新按钮或正文格式／撤销／重做工具栏。

点击新建立即创建正式 Markdown 并聚焦正文；初始页面直接写也自动创建。不要求文件名或首次提交，创建后可在文档顶部改名。使用 CodeMirror 6 的 Markdown 编辑、即时标记显隐及键盘编辑，保留独立阅读预览。标题内 Enter／离开确认改名，Esc 取消；输入法组字期间不提交。

自动保存是唯一模式；Ctrl／⌘S 可立即保存。切换或新建先等当前内容保存成功，失败停留；文件冲突或未知结果直接提示，保留当前输入，可核对文件或明确保存副本。未知结果不自动重发。独立的编辑会话隔离撤销，改名和首次创建确认不重置光标／撤销。

移除笔记草稿库、恢复界面、历史、回收站、删除入口、手动模式开关和单独的原话捕获流程。输入在当前会话中保留，未保存关闭页面时提醒；不承诺刷新／崩溃恢复。旧数据保留，当前插件不读写旧 IndexedDB 或历史目录。旧版说明见 [v0.30 归档](history/PRODUCT-SPEC-v0.30.md)。

## 待办：记下一件事，做完就勾

参考开源 [Vikunja 的快速添加](https://github.com/go-vikunja/vikunja/blob/main/frontend/src/components/tasks/AddTask.vue)、[任务行](https://github.com/go-vikunja/vikunja/blob/main/frontend/src/components/tasks/partials/SingleTaskInProject.vue)与[详情说明](https://github.com/go-vikunja/vikunja/blob/main/frontend/src/components/tasks/partials/Description.vue)，以及 [Super Productivity](https://github.com/super-productivity/super-productivity) 的清单与键盘操作（对照其官方演示 `docs/screens/reel.gif`）。复用常见交互模式，不嵌入整套 Vue／Angular 应用，也不引入项目管理或时间追踪流程。

默认入口为一个快速输入框和清单。输入标题后回车新增，成功清空并继续聚焦输入框；列表勾选直接完成，反馈可撤销。状态切换和搜索清楚可见，标题／首行说明组成行内容，不重复每行同一状态文案。

快速录入行位于清单内，状态和搜索位于其上方；从已完成视图新增后回未完成，从全部视图新增保持全部，成功新增会清除当前搜索，让新事项可见。清除搜索提供直接入口。页头只保留轻量 JSON 导出按钮，没有更多菜单或重复新建表单。

列表聚焦时 N 回到快速输入，/ 聚焦搜索，上下方向键移动任务标题焦点，Enter 打开；输入框内不截获字符，组字期间不导航或提交。Esc 从详情保存后返回；冲突、失败和未知结果仍阻止离开。

点标题按需查看详情。桌面在列表旁打开内容面板，手机进入独立详情并能返回；标题和说明直接编辑，顶部保留完成勾选、轻量状态和关闭操作。正常已有事项不再显示独立的保存／完成按钮区或多层表单标题。标题自动换行，说明按内容伸缩，有行数上限以保留其他操作空间；短说明不常驻大文本框。图标使用 Lucide，伸缩复用 react-textarea-autosize，均使用宿主 React。

默认在离开编辑区域、切到另一事项或返回列表时保存已修改详情，再继续目标操作。插件内动作统一安排保存与后续请求，第一次点击不能因为 blur 触发保存而被吞掉。组字期间不提交；失败／冲突留在原内容，未知结果保留原 UUID 供明确重试，不能自动换号或重发。版本检查及同一请求重试由内部服务处理。

移除草稿库、恢复／丢弃、手动模式、笔记关联和取消功能。输入只在当前会话保留，未保存关闭时提醒，不承诺刷新／崩溃恢复；旧数据库和浏览器草稿不删除。旧取消记录与关联仅保留在原始数据库和 JSON 导出中。

## 辅助与异常

笔记没有恢复、历史、回收站或手动模式入口。手机正文、列表和阅读预览不纵向堆叠。

存储失败、版本冲突、未知提交和身份改变不是可折叠的普通说明，必须在当前流程直接可发现。只在落盘确认后显示已保存；待办未保存输入不是主机记录或备份；笔记改名遵守版本与进行中操作锁。

窄屏输入至少 16px、主要触控目标至少 44px，工具栏和主要操作在缩小视口仍可达。最终应查看正常桌面／手机画面，并完整走过新建→输入→切换→再打开，以及新增→详情编辑→切换→完成／撤销；保留录入和保存错误的独立回归。Chromium 触控模拟不代表物理手机、原生输入法或 WebKit 已验收。

日期、日程、提醒、联动和自动记忆仍暂缓，工具执行计划不混入个人待办；不增加虚假的日历或提醒入口。
