## 笔记工作区

在 DSH 中打开 Files.md 笔记面板，只用于查看和编辑笔记：保留文件树、编辑、查找、改名、移动、归档、分栏、日记和清单菜单，不显示收集页和 Agent 按钮。工作区打开上次查看的笔记，没有则打开最近修改的笔记，资料为空时提示新建。配色与待办一致：暖灰侧栏、白色正文、单一蓝色强调。Files.md 界面文案跟随宿主语言，笔记名与正文不翻译。新笔记选中占位标题，直接输入即可命名。切换到其他宿主面板前先保存，返回保持 iframe 编辑状态。保存冲突保留输入，不静默覆盖外部修改。

## 任务与日历

新实例启用 todos planner。左侧栏列出今天、未来、收集箱、全部（带未完成计数）、日历、提醒、各个清单（带计数）以及已完成和已取消；窄屏时侧栏收为抽屉。任务视图顶部可直接输入标题回车添加。支持搜索、筛选和分页，今天区分逾期、今日与此前计划，顶部列出当天日程与任务时间块。在今天、未来或清单筛选下新建任务会预填对应日期或清单。显示时区直接采用本机时区并按浏览器记住，可在时区弹层明确更换。

新增与详情编辑支持日期、截止、优先级和清单。日期截止与精确时刻分开输入。精确截止、提醒和定时日程起止使用「日期 + 时间」控件，按记录所属时区理解；夏令时造成的不存在或重复时刻列出带偏移的候选，由用户选择。提醒提供快捷时间，已过时间就地提示。详情通过显式保存提交；未知请求先查询回执，不立即重复写入。

日历可切月、周、日和议程，支持独立事件、全天事件和任务时间块。拖动或拉伸先恢复当前显示并打开待保存表单，确认后提交；表单提供等价操作。开始时间有效变更保留时长，结束时间排他。

提醒在站内保留记录。网页通知由用户主动授权；关闭页面不提供后台推送，不将一次通知认领描述为送达保证。

planner 使用紧凑顶部导航、分组任务列表、可收起筛选及统一日历。宽屏详情与列表分列，窄屏导航可横向滚动、详情全宽显示；使用宿主浅深色与中英文设置。普通表单控件保留清楚的键盘焦点，错误与未知结果在详情中就近呈现。

冲突预览列出任务／日程的全部可编辑字段及已清空值，继续编辑不隐藏恢复入口。保留输入前须核对完整表单；采用服务器版本后清除冲突提示。保存和核对结果时，列表刷新结束或超时后可以再次提交，期间新增输入仍保留。

## 学习导师

用户安装插件后在已有 DSH 工作区选择「学习导师」预设。插件不强制打开目录或切换默认预设。路线、靶图、进度和反馈卡片随回答展示；规划中的路线与靶图支持直接编辑，经宿主鉴权及版本检查保存。个人笔记编辑不授予验证成绩。互动题与闪卡使用原生右侧学习工作区；详细交互见 [导师指南](../packages/learn-anything/README.md)。

## 兼容与验收

旧 notes classic 与 todos v1 保留各自界面，不自动转为新版。未交付的笔记来源关联、重复与外部通知不应展示为可用入口。

浏览器测试覆盖应按 Files.md、planner、旧版兼容页面与导师分别记录。窄屏 Chromium 检查不等同物理手机验收；实际执行结果以 [交接记录](HANDOFF.md) 为准。
