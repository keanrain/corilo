# Corilo 可里交互设计

v0.33 · 2026-11-11。采用 [Files.md](https://github.com/zakirullin/files.md) 完整前端，固定来源见 `plugins/notes/vendor/filesmd/SOURCE.json`。本轮用户要求先保留菜单和功能，裁剪后置；不再把自定义 React 笔记页作为默认体验。

工作区保留原生文件树、新建文件／目录、查找、随机打开、标题内改名、移动／归档、分栏、链接、Markdown 编辑、收集、日记和清单交互。文本编辑使用其 CodeMirror／HyperMD。顶端增加轻量主机保存状态和 Agent 入口，给原工作区预留空间，不能遮挡收集发送或手机操作。

Files.md 的 chat 是写入 Chat.md 的收集界面。它与 Harness 的模型会话分工明确：普通收集、日记和清单操作不调用模型；Agent 按钮先保存当前修改，再切到 Harness 原生会话。返回工作区保留同一个 iframe、分栏和编辑状态。Agent 通过共享工具操作同一资料，不再显示另一套 Pi 对话或模型配置。

浏览器读写主机目录，不要求在每台设备选择本地文件夹。原生打开目录入口解释目录由主机配置；外部机器人服务入口提示使用 Agent，不伪装已经连接 Telegram、语音转写或通知服务。保留可用本地语音文件记录能力，实际麦克风依浏览器授权与设备验收。

保存按实际读取版本校验，失败不标记干净、不覆盖另一份文件。冲突保留输入，可核对文件、明确采用文件内容或保存副本。未知写入暂停该文件后续写入，只读核对后再继续；收集丢响应也不能重复发送。组字期间不保存当前编辑器，不通过导航丢掉未保存输入。未保存关闭时提醒，不承诺浏览器崩溃恢复。

待办采用原生 Markdown 复选框；旧 SQLite 已完成映射为勾选，未完成映射为未勾选，取消记录不重新打开。旧字段在归档迁移记录里保留。迁移前后的现有文件和旧数据库均可核对，不同时维护两套“当前待办”。

当前 Chromium 桌面／390px 验收与真实物理手机、原生输入法、麦克风、WebKit 分别记录。可靠提醒和通知不因这次页面移植而视为交付。
