# Corilo 可里交互设计

v0.14 · 2026-10-21。云端邀请版；行为以 [业务规格](PRODUCT-SPEC.md) 为准，以下描述目标交互，现有登录、文件与导出入口只是部分实现。

## 简单优先

目标首页为一个输入框、最近对话与少量需要关注的事项。用户不必先理解知识库结构；文件、记忆、待办和日程按需打开。资料中心提供范围明确的导出，避免用“全部数据”描述局部能力。当前已有页面先增加“导出知识库”，首页重组、记忆纠正和提醒管理尚待实现。

## 页面结构

桌面和手机默认进入对话输入与少量需关注事项，提供资料和事项入口；文件树不作为理解产品的前置步骤。进入资料后，桌面使用文件列表、搜索与完整 Files.md 编辑器，结果文件可分屏打开；手机文件详情全屏，返回保留会话位置与草稿。待办、日程、提醒状态按需展开，账号菜单承载设置，避免默认铺开多套复杂管理界面。网页同时适配 Android Chrome 和 iPhone Safari，不展示本地运行环境初始化或终端启动步骤。

```text
Corilo                              已保存到云端
对话 / 资料 / 事项                  当前会话
                                     你：把讨论整理进项目笔记
                                     Agent：正在读取项目笔记… [停止]
                                     已更新 项目/可里.md [打开]
                                     [输入消息……] [发送]
                                     [仅保存原话]
```

对话仍参考 Bot 的短输入、进度和结果形式，目录与分类由 Agent 判断。界面不暴露容器、Pi 配置路径或任务租约等实现细节。

## 首次使用

以下是目标流程；当前开发实现是预开通并验证的账号、邮箱/密码与首次邀请码，尚无应用邀请链接开通、验证码或密码恢复流程。最终开通方式见业务规格第 8 节，不宣称已交付一键邀请体验。

1. 从邀请入口完成身份验证；无权限或邀请无效时说明原因，不创建空白知识库假装成功。
2. 显示资料存储与 AI 使用说明，进入自己的空知识库，可创建笔记或导入资料。
3. 可直接编辑；模型由服务端准备，没有模型可用时明确提示 AI 暂不可用，文件编辑仍可使用。
4. 无需安装 APK、配置 GitHub 仓库或填写模型密钥。登录另一台设备后看到同一份云端内容。

## 保存与冲突

顶栏区分“未保存”“正在保存”“已保存到云端”“网络中断，草稿未保存”和“文件已有新版本”。不再显示本机已保存/GitHub 待同步。

有新版本且本页无草稿时刷新内容；有草稿时保留编辑器，提示查看新版本、另存副本或合并后保存。手机使用版本切换，不强制三列对比。保存失败时不清空文本；离开页面有未保存内容时提醒。首期离线不展示可用完整知识库的承诺。

## 对话与任务

排队时显示“等待执行”，不要编造精确时间；额度不足说明限制与恢复方式。运行时显示必要工具进度、停止按钮与结果，详细信息可展开。发送后输入区可继续写下一条草稿，但同库不并行启动第二个修改任务。

网页关闭或手机切后台后服务端仍可能运行。回到前台或另一设备打开会话时先加载持久状态，再接续进度，不能自动重发上一条消息。停止中保持状态，确认执行结束后显示已停止；已修改文件仍可打开。服务重启留下的中断说明已知结果，由用户决定是否继续。

Agent 运行时笔记可读，编辑入口提示先停止任务。另一设备的未保存文本保留，任务结束后需要版本核对。结果卡包含实际文件路径和打开入口；文件不存在时说明，不伪造结果。

## 账号与资料管理

设置只放账号/退出、容量与 AI 额度、导入/导出、历史恢复和删除资料入口；不在首期加入支付或 GitHub 绑定页面；记忆纠正、待办完成和一次性提醒修改属于资料/事项的直接操作，不塞入设置页。历史恢复先预览并确认目标版本，恢复后成为新版本。删除账号说明作用范围与备份保留期，不以含糊“永久立即删除”替代实际行为。

## 移动端检查

首期实测中文输入法组合输入、软键盘遮挡、滚动位置、文件返回、长对话与大文件、前后台切换、网络恢复、复制粘贴与文件下载。优先使用浏览器基本能力；基本编辑/对话不以 PWA 或商店上架为前提。提醒渠道尚未选定，需单独验证目标手机上关闭网页后的投递条件、授权、时区和失败反馈；不得用站内提示冒充后台送达。
