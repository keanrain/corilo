# Corilo 可里交互说明

2026-11-15。描述当前产品入口与交互边界；原布局设想见 [v0.34 交互方案](history/v0.34/DESIGN.md)，业务规则见 [规格](PRODUCT-SPEC.md)。

## 笔记工作区

在 DSH 中打开 Files.md 笔记面板，保留文件树、编辑、查找、改名、移动、归档、分栏、收集、日记和清单菜单。切换 Agent 前先保存，返回保持 iframe 编辑状态。保存冲突保留输入，不静默覆盖外部修改。

## 任务与日历

新实例启用 todos planner。任务视图包括收集箱、今天、未来、全部、已完成和已取消；日历与提醒为独立面板视图。支持搜索、筛选和分页，今天区分逾期、今日与此前计划。

新增与详情编辑支持日期、截止、优先级和清单。日期截止与精确时刻分开输入。详情通过显式保存提交；未知请求先查询回执，不立即重复写入。

日历可切月、周、日和议程，支持独立事件、全天事件和任务时间块。拖动或拉伸先恢复当前显示并打开待保存表单，确认后提交；表单提供等价操作。开始时间有效变更保留时长，结束时间排他。

提醒在站内保留记录。网页通知由用户主动授权；关闭页面不提供后台推送，不将一次通知认领描述为送达保证。

planner 0.6.3 使用紧凑顶部导航、分组任务列表、可收起筛选及统一日历。宽屏详情与列表分列，窄屏导航可横向滚动、详情全宽显示；使用宿主浅深色与中英文设置。普通表单控件保留清楚的键盘焦点，错误与未知结果在详情中就近呈现。

## 学习导师

用户安装插件后在已有 DSH 工作区选择「学习导师」预设。插件不强制打开目录或切换默认预设。路线、靶图、进度和反馈卡片随回答展示；规划中的路线与靶图支持直接编辑，经宿主鉴权及版本检查保存。个人笔记编辑不授予验证成绩。互动题与闪卡使用原生右侧学习工作区；详细交互见 [导师指南](../packages/learn-anything/README.md)。

## 兼容与验收

旧 notes classic 与 todos v1 保留各自界面，不自动转为新版。未交付的笔记来源关联、重复与外部通知不应展示为可用入口。

浏览器测试覆盖应按 Files.md、planner、旧版兼容页面与导师分别记录。窄屏 Chromium 检查不等同物理手机验收；实际执行结果以 [交接记录](HANDOFF.md) 为准。
