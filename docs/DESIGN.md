# Corilo 可里交互设计

v0.12 · 2026-10-09。行为以 [业务规格](PRODUCT-SPEC.md) 为准。

## 页面结构

桌面：左栏为对话、文件、搜索和设置；中心为当前对话或完整 Files.md 编辑器；打开结果文件可使用右侧阅读/编辑区域。手机：对话和文件为主要入口，文件详情全屏，返回回到原对话位置。两端共享页面与业务组件，Android 使用 WebView，桌面使用 Chrome。

```text
Corilo                         本机已保存 · 待同步 2
对话 / 文件 / 搜索             当前会话
                               你：把今天的讨论整理进项目笔记
                               Agent：正在读取项目笔记… [停止]
                               已更新 项目/可里.md [打开]
                               [输入消息……] [发送]
                               [仅保存原话]
```

对话借鉴原 Bot 的短输入、进度、结果方式，但分类、保存目录和工具步骤交给 Agent 判断。避免每条输入先展示一排处理模式。需要用户选择时，Agent 用简短问题解释选择影响。

## 首次使用

1. 点击桌面启动器或 APK，显示环境准备进度；已经安装后不重复下载整套环境。
2. 创建本地知识库或选择本机目录。Android 默认应用私有目录，提供导入/导出，不承诺任意 SAF 目录能直接作为 POSIX 工作树。
3. 可立即进入文件页面；使用 AI 前填写 DeepSeek 配置，沿用 Pi provider/model 配置语义。
4. 同步可稍后设置；设置中连接私有 GitHub 仓库并显示连接结果。密钥输入默认遮盖，不进入对话。

没有 AI 配置时仍能记笔记；没有网络时发送按钮说明模型暂不可用，并保留输入。

## 对话状态

准备 → 运行中 → 完成、已停止或失败。运行中显示必要工具动作，详细日志默认折叠。点击停止不撤回已修改文件；结果列出已经完成的操作。正在运行时允许输入草稿，首期不同时启动第二个修改知识库的 Agent。

文件卡片包含路径、操作和打开按钮；打开失败说明文件已移动或删除，不显示过期内容作为实时文件。Agent 运行期间编辑器可查看，修改入口提示先停止当前执行。结束后刷新打开的文件。一般回答无需生成文件卡。

## 保存与同步反馈

“本机已保存”和“GitHub 已同步”是两个状态。顶栏点击同步状态打开详情，不用全屏打断编辑。

| 状态 | 显示与操作 |
|---|---|
| 未连接 | 本机使用；设置同步 |
| 待同步 | 本机已保存；展示待上传提交或变更摘要 |
| 正在同步 | 当前步骤，避免伪造精确百分比 |
| 已同步 | 最近成功时间 |
| 离线/认证失败 | 本机内容保留；重试或更新凭据 |
| 有冲突 | 文件列表；查看双方、保留本机/远端/两份、编辑合并 |

冲突详情默认并列或切换显示版本。手机避免三列对比，使用版本切换和清晰操作。处理完成后继续同步；不把 Git 原始错误堆栈作为唯一说明。

## 生命周期

桌面关闭网页不等于中断 Agent；启动器提供运行状态与退出入口，退出时提示活动执行。Android 切后台尝试按系统要求维持运行，系统终止后下次进入显示中断状态，保留已保存文件；不自动重放命令。

升级或初始化失败停留在可恢复页面，提供重试和查看诊断；不要求用户打开终端修复常规问题。首期不制作额外 Today、日历和系统提醒页面。
