# Corilo 可里交互设计

v0.17 · 2026-11-08。DeepSeek Harness 为主体，业务规则见 [PRODUCT-SPEC.md](PRODUCT-SPEC.md)。以下为目标交互，插件工具注册不代表这些页面已完成。

保留 Harness 原有对话、会话、模型设置、工具进度和停止体验。Corilo 通过插件增加“笔记”和“事项”入口；不再把旧 Files.md/Pi 应用嵌套为另一套主界面。桌面与手机使用同一服务，手机无终端初始化流程。

笔记入口包含列表/搜索、正文编辑和仅保存原话。Agent 整理结果可打开对应真实笔记；用户也能直接编辑，不必每个动作都发对话。新手不用先选分类或数据库。编辑显示未保存、保存中、已保存、失败与版本冲突；失败保留草稿，冲突可核对最新内容或另存。外部变化时不自动覆盖未保存文本。

事项插件提供用户待办和日程视图，工具执行计划不混入个人事项。事项卡显示标题、日期/时区、完成及提醒状态，支持直接修改/取消。渠道未配置显示“提醒未启用”，不借模型文本显示成功。通知渠道、授权与手机后台行为尚待确定和实测。

后续记忆显示内容与来源并支持更正/忘掉。资料管理明确区分笔记文件导出、完整数据包与系统备份，各自标注范围。历史导入不继续执行旧会话或重发提醒。

首期对话和笔记入口优先；工具层、Web 页面、真实模型、手机与部署分别记录验收。Harness 默认界面的移动可用性也必须实际检查，不能由 Web UI 存在推断通过。
