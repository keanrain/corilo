# Corilo 可里业务规格

历史快照：此版本已由 v0.34 取代。只保留当时规则与证据；当前需求见 [设计索引](../README.md)。
v0.33 · 2026-11-11。本文件是当前规则唯一来源。用户授权以 Harness 为主体，移植 Files.md 完整前端、先保留菜单与功能，并将机器人资料操作交给 Agent。先前自定义极简页面要求见 [v0.32](PRODUCT-SPEC-v0.32.md)，不再作为默认工作区的裁剪依据。

## 1. 范围与部署

首期个人 Linux 小主机／常开电脑自部署，浏览器连接同一主机目录。Harness 提供身份、模型、会话、权限和 Agent 运行机制。不得另建 Pi 或模型管理主链路，不连接 Files.md Go 同步、托管 API 或 Telegram 服务。NAS 先作备份，不宣称未经验证的 SMB／NFS 或双向同步为工作盘。官方账号、Supabase 和 GitHub 绑定均不是使用条件。

## 2. 统一工作区

主包为 plugins/notes，默认 Files.md 工作区；旧 React／CodeMirror 6 笔记页可用 interface: classic 兼容。新源码配置只加载工作区包。旧双插件配置继续有效，不能自动重写、删除或迁移用户数据。

保留 Files.md 文件树、新建文件／目录、查找、改名、移动、归档、随机打开、分栏、链接、收集、Markdown 清单和日记交互。页面通过 Harness 路由访问文件，浏览器不直接访问主机磁盘或同步另一套本地副本。打开目录入口由主机配置解释，外部机器人／服务相关操作明确提示当前未连接，以 Agent 作为资料操作入口。

笔记和待办为 UTF-8 Markdown，Chat.md 为收集文件，Later.md 为待办清单，journal/ 为日记，附件保留原字节，config.json 为 Files.md 设置。隐藏路径、路径穿越、链接与特殊文件拒绝；单篇正文／设置上限 1 MiB，单附件 16 MiB，单目录累计读取上限 64 MiB，目录扫描最多 20000 项／20 层并有 10 秒预算，超限明确失败。仅隐藏原生文件树中的隐藏项；移动／删除包含隐藏或不安全后代的目录应拒绝。

页面与 Agent Markdown 工具共用业务服务和进程内队列。更新检查实际读取的内容 SHA-256；移动、删除检查读取到的文件或目录版本，目标存在时拒绝覆盖。失败保留当前输入，提交后未知结果先只读核对，不自动重发或伪装回滚。服务队列不承诺对任意外部编辑器／默认 bash 工具提供跨进程事务。

编辑器提交中继续输入时只确认已提交快照；组字期间暂停提交。收集成功后才清空对应输入；丢响应不能重复写同一收集记录，核对一致后才确认。正常导航先保存；关闭未保存页面提醒，不承诺刷新／崩溃恢复。Files.md 自身菜单中的归档与文件操作按原生语义保留，不增加自动备份或新的浏览器草稿库。

## 3. Agent

使用 Harness 原生会话和当前模型设置。用户明确要求记录／修改资料时才调用对应工具；普通编辑、保存、清单勾选、收集及日记为确定性操作，零模型请求。Agent 执行计划不混为个人待办。机器人原有“记录、查找、待办、日记”能力通过 Agent 读写同一 Markdown 实现，不把 UI 入口或测试管线当真实模型联调证明。

## 4. 旧待办迁移

plugins/todos 保留为存量兼容包，不在新配置默认加载。`corilo-import-todos --source /absolute/todos.sqlite --root /absolute/notes` 默认只输出预览；`--apply` 才导入。运行前停止源和目标服务并备份，原 SQLite 只读且保留。现有 Later.md 不被截断，未完成／完成映射为 Markdown 复选框；取消记录不变成待办。原字段、关联和取消记录在 archive/ 的迁移记录中逐字保留为公开 JSON。

迁移记录包含源身份与内容指纹、目标前后版本及 planned／complete 状态。同源重试不重复追加；源发生后续变化或目标在未完成导入期间改变时拒绝继续，保留资料供核对。中断后目标已提交时只补确认，不再次追加。目标和迁移记录分别最多 1 MiB，超限在写入前失败。迁移成功不自动删除数据库、卸载旧包或改写现有 overlay；确认迁移后可将旧双插件配置改为已支持的单插件配置。
