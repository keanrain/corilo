# Corilo 可里业务规格

v0.17 · 2026-11-08。本文件是当前产品规则唯一来源。用户决定采用 DeepSeek Harness 主体加笔记、日程插件，近期优先个人自部署。旧云端邀请版规则保留在 [v0.16 历史归档](history/PRODUCT-SPEC-v0.16.md)，不覆盖本规格。未实现功能均是目标，不是已交付承诺。

## 1. 产品与部署范围

首期单用户，服务和资料由用户自己的常开设备承载；浏览器跨设备访问同一服务，不要求手机运行 Agent。Harness 提供对话、模型设置、会话及默认工具，Corilo 通过公开插件接口扩展。初期 DeepSeek，不另造模型管理、Agent loop 或权限审批框架。

工作资料保存在主机本机磁盘；NAS 先承担备份。不能将未经验证的网络共享、客户端双向同步、休眠主机宣称为可靠全天服务。公网暴露前必须实际验证身份、来源和网络边界；个人模式不是无鉴权远程公开服务。远程访问方式、具体硬件和 OS 尚未选定。

## 2. 笔记与文件

笔记为普通 Markdown，附件保持原文件格式；笔记正文唯一权威为磁盘文件，不是浏览器临时状态或模型总结。配置、凭据、会话、执行日志和业务数据库在知识库外。

支持浏览、读取、搜索、直接编辑及“仅保存原话”。保存原话不调用模型，不归纳或改写文本。Agent 可直接使用 Harness 默认文件工具；Corilo 笔记工具与后续笔记页面共用同一服务。必要歧义才询问，目录与整理步骤由 Agent 判断。普通讨论不自动写文件。

保存落盘后才显示成功；失败保留草稿。页面或插件管理的更新、删除和移动必须检查用户实际读取的版本；版本冲突拒绝覆盖并允许另存或核对最新内容。插件服务串行自己的变更；Harness 默认文件/bash 工具或外部进程不自动受该队列控制，不因此承诺跨进程文件事务或完全消除外部写入竞争。

拒绝插件接口中的路径穿越、隐藏运行目录、危险链接与特殊文件，读取和扫描有明确上限；不静默截断后宣称完整。默认 Agent 工具仍沿用 Harness 自身的隔离和策略，插件路径校验不等于默认 bash 的安全沙箱。

## 3. 对话与结果

沿用 Harness 原生会话、工具进度、停止和恢复能力。关闭网页不是停止，重连不自动重发原请求。旧 Pi 会话不自动导入为 Harness 可执行会话；任何历史导入不得执行旧工具。

模型承诺不能代替实际文件或结构化记录成功。结果与失败应可查询，实际修改保留；不承诺停止时自动回滚。工具接入不等于完整笔记界面已完成，桌面检查不等于手机验收。

## 4. 个人事项与提醒

用户待办 todo、日程 event、提醒 reminder 与 Agent 执行任务是不同概念。Harness 内部执行计划或工具 todo 不自动成为个人事项。Corilo 事项插件提供同一业务服务的直接 UI 操作与 Agent 工具。

首版考虑个人待办、一次性内部日程、一次性提醒及 ICS 导出；周期规则和外部日历双向同步后置。创建待办不自动创建提醒，日程结束不自动完成待办。修改/完成/取消检查版本，重复请求不重复创建对象。

提醒保存确定时刻、时区和通知渠道。歧义时间及夏令时冲突需澄清；渠道未启用只能保存事项，不能回执“已安排通知”。持久调度负责重启恢复、发送竞争、取消与未知投递，不用模型记忆或浏览器/内存定时器代替。主机离线期间无法投递，恢复后的补发策略须明确，不盲目重发。提醒渠道尚未选定，未经授权不发送邮件或他人日历邀请。

## 5. 记忆

后续支持明确“记住、更正、忘掉”，保存内容、来源、时间和版本，用户可直接查看修改。用户陈述不冒充外部核实，推断与已确认内容区分。自动提取策略尚未决定，不默认无限留存或逐条强制审批。

忘掉记忆需停止其检索和自动注入，并区分原始笔记/会话是否仍保留；不承诺删除模型供应商已接收内容或用户备份。遗忘记录与旧包恢复的语义须随记忆功能一起设计和验收。

## 6. 数据自主与备份

正文和附件可直接阅读；事项与记忆提供版本化公开格式，完整资料包最终包含对话、关联与偏好，并明确排除凭据及内部诊断。局部知识库 ZIP 不能称完整账号备份。导入先校验，不能默认覆盖已有资料、执行历史工具或发送旧提醒。

本地版本历史与独立备份分别建设；NAS 备份需协调文件、会话和业务数据的一致性，并实际恢复比对。备份/保留周期尚未确定；拥有 NAS 不等于已完成备份交付。GitHub 不是使用或同步前提。

## 7. 分阶段验收

| 编号 | 条件 |
|---|---|
| H01 | 固定版本 Harness 真实加载独立 Corilo 插件，重启后可恢复配置，不修改其 Agent loop |
| H02 | 工具操作真实 Markdown，原话逐字保留，重开相同；零模型直接保存可验证 |
| H03 | 旧版本更新拒绝，越界/链接/特殊文件/超限拒绝；失败不丢原文件 |
| H04 | Harness Web 内笔记列表、读取、编辑和原话保存完整可操作，失败保留草稿 |
| H05 | 桌面、Android 和 iPhone 跨设备访问、重连、中文编辑及冲突实测通过 |
| H06 | 真实 DeepSeek 通过默认工具/Corilo 工具完成读写，成功回执对应真实文件 |
| H07 | 个人部署不依赖 Corilo 官方服务或 Supabase，远程访问鉴权与隔离范围实测 |
| H08 | 事项可直接及经 Agent 创建、修改、完成、取消，具备持久化及幂等/版本保护 |
| H09 | 提醒实际调度/投递/取消与重启恢复可验证，未知结果不伪造成功或盲目重发 |
| H10 | 记忆可查来源、纠正和忘掉，不重复提取已抑制内容，不把推断当事实 |
| H11 | 完整资料导出/恢复及 NAS 备份恢复比对通过，历史不产生新执行或通知 |

验收必须单独记录实际覆盖，不用旧 C/N 编号通过数量替代 H 系列。首轮插件文件服务和工具检查只覆盖 H01–H03 的相应部分。

## 8. 待决定项

具体常开主机/NAS 型号和 OS、远程认证/网络方式、通知渠道、自动记忆范围、备份与会话保留期、日程插件存储实现尚未决定。实现可选简单可迁移的本地存储，不要求沿用旧云端 PostgreSQL，但必须区分方案建议和实际实现。不得因底座切换自动迁移或删除现有用户数据。
