# Corilo 可里业务规格

v0.27 · 2026-11-09。本文件是当前产品规则唯一来源。用户决定采用 DeepSeek Harness 主体加笔记、日程插件，近期优先个人自部署。旧云端邀请版规则保留在 [v0.16 历史归档](history/PRODUCT-SPEC-v0.16.md)，不覆盖本规格。未实现功能均是目标，不是已交付承诺。

当前优先级已收敛为核心笔记/待办与良好体验，暂缓截止日期、笔记联动、日程、提醒与自动记忆。已有历史/回收站/导出保留在次级入口，不扩充主操作负担。以下未来目标不能作为当前追加功能的授权。

## 1. 产品与部署范围

首期单用户，服务和资料由用户自己的常开设备承载；浏览器跨设备访问同一服务，不要求手机运行 Agent。Harness 提供对话、模型设置、会话及默认工具，Corilo 通过公开插件接口扩展。初期 DeepSeek，不另造模型管理、Agent loop 或权限审批框架。

工作资料保存在主机本机磁盘；NAS 先承担备份。不能将未经验证的网络共享、客户端双向同步、休眠主机宣称为可靠全天服务。公网暴露前必须实际验证身份、来源和网络边界；个人模式不是无鉴权远程公开服务。首个目标为 Linux 小主机/常开电脑；具体硬件、发行版及远程访问方式尚未选定。

长期运行复用系统服务管理，固定持久 Harness home、共享 Agent 配置根、工作目录和端口。检查时报告解析位置，凭据/会话目录不得与笔记或恢复状态重叠。进程重启不自动重发捕获或覆盖草稿；机器开机、用户登录、自启与休眠恢复须分别验收。

## 2. 笔记与文件

笔记为普通 Markdown，附件保持原文件格式；笔记正文唯一权威为磁盘文件，不是浏览器临时状态或模型总结。配置、凭据、会话、执行日志和业务数据库在知识库外。

支持浏览、读取、搜索、直接编辑及“仅保存原话”。新建时可留空标题自动命名，填写普通标题则在保存时补 `.md`；正文逐字保留。手机列表与正文切换而非堆叠，打开和新建后焦点回到正文。编辑区内 Ctrl／⌘S 执行同一显式保存，组字时不提交。保存原话不调用模型，不归纳或改写文本。Agent 可直接使用 Harness 默认文件工具；Corilo 笔记工具与后续笔记页面共用同一服务。必要歧义才询问，目录与整理步骤由 Agent 判断。普通讨论不自动写文件。

已保存过且持有版本的笔记支持停止输入后自动保存，提交期间允许继续输入，响应仅确认提交快照，不覆盖随后输入。新笔记首次仍显式保存；恢复草稿本身不触发自动写入。组字期间不提交；内容未变不重复写入，保存中合并后续修改。冲突、失败或结果未知时停止自动提交，需用户核对或明确保存，不能靠定时器盲目重试。Markdown 预览仅渲染当前正文，原始 HTML 不执行，图片及其他外部资源不主动加载，超出预览上限明确提示而不影响正文编辑保存。

已保存笔记支持同目录重命名，显式确认目标，检查读取版本且拒绝覆盖同名目标。正文有未保存修改时先保存正文；重命名期间禁止自动保存及其他文件变更。新旧路径的历史都保留且可发现，不自动修改 Markdown 链接或待办关联路径。落盘与历史记录不是跨目录事务；部分完成或结果未知须明确回执，并先核对新旧文件，不自动重试。

保存落盘后才显示成功；失败保留草稿。页面或插件管理的更新、删除和移动必须检查用户实际读取的版本；版本冲突拒绝覆盖并允许另存或核对最新内容。插件服务串行自己的变更；Harness 默认文件/bash 工具或外部进程不自动受该队列控制，不因此承诺跨进程文件事务或完全消除外部写入竞争。

页面使用不读取整库正文的有界元数据分页，支持文件名和正文的显式字面搜索，搜索无模型调用。扫描、正文、结果有上限；超限明确报错或标记截断，不把部分结果称为全部。按已知相对路径打开不依赖列表扫描成功。旧完整版本列表接口保留兼容限制，不作为新页面入口。

切换笔记或新建时，当前未保存内容先原子保留为独立浏览器草稿，成功后才切换；保留失败则停留在原编辑器。草稿列表提供正文摘要及只读预览；主动丢弃仍需明确操作。历史支持继续读取更早记录；手动本机压缩不得删除逻辑对象、版本或引用，不自动决定保留期限。

浏览器草稿是恢复副本，不是已保存笔记或独立备份。草稿按知识库和页面隔离，重载后由用户明确恢复或丢弃；恢复不自动写磁盘，并沿用草稿原来的文件版本。存储不可用时明确提示；知识库身份未确认或已切换时，旧页面不能继续向新库写入。

配置独立恢复目录后，插件管理的变更使用本机 Git 保存检查点，删除进入回收站；恢复版本仍检查当前文件版本，回收站恢复只新建、不覆盖。历史、配置和回收站数据位于知识库之外，不修改用户原有 Git 仓库。外部工具的中间修改不承诺持续记录。文件变更与历史确认不是跨文件系统事务；已落盘但确认失败时须明确部分完成，不能假装回滚或自动重试。

拒绝插件接口中的路径穿越、隐藏运行目录、危险链接与特殊文件，读取和扫描有明确上限；不静默截断后宣称完整。默认 Agent 工具仍沿用 Harness 自身的隔离和策略，插件路径校验不等于默认 bash 的安全沙箱。

## 3. 对话与结果

沿用 Harness 原生会话、工具进度、停止和恢复能力。关闭网页不是停止，重连不自动重发原请求。旧 Pi 会话不自动导入为 Harness 可执行会话；任何历史导入不得执行旧工具。

模型承诺不能代替实际文件或结构化记录成功。结果与失败应可查询，实际修改保留；不承诺停止时自动回滚。工具接入不等于完整笔记界面已完成，桌面检查不等于手机验收。

## 4. 个人事项与提醒

用户待办 todo、日程 event、提醒 reminder 与 Agent 执行任务是不同概念。Harness 内部执行计划或工具 todo 不自动成为个人事项。Corilo 事项插件提供同一业务服务的直接 UI 操作与 Agent 工具。

当前首版个人待办使用独立插件：标题、详情、关联笔记相对路径及未完成/已完成/已取消状态，支持重新打开。关联只保存路径，不保证文件存在或重命名后自动修复。标题去掉首尾空白后 1–200 字符，详情最多 20000 字符，关联 Markdown 路径最多 1024 字节；拒绝无效 Unicode、隐藏路径和路径穿越。完成/取消保留记录，不物理删除。

页面和工具共用 SQLite 服务，修改/完成/取消/重新打开检查读取时的整数版本。持久请求 UUID 与变更在同一事务提交；相同 UUID/内容重试返回原提交结果，异内容拒绝，不能重复新建。版本冲突保留编辑内容供核对；结果未知保留原请求，由用户明确重试，不自动换 UUID。待办支持只填标题的快速连续新增，以及列表直接完成/撤销，行操作不得覆盖其他编辑草稿。草稿复用 IndexedDB 持久恢复，按 SQLite 身份和页面隔离；包括详细编辑输入、快速输入及结果未知的完整请求 UUID。恢复不自动重发，保存/丢弃与多标签竞争使用事务及内容校验，不能删掉另一页面的新草稿。提交前先等待正常可用的浏览器草稿保护；存储失败要明确告知，保留内存输入，直接保存仍可用，不假称刷新可恢复。旧页面遇到资料库身份改变时暂停写入。

页面以状态按钮和常显搜索查找待办，详情在桌面侧栏、手机独立视图打开。切换详情、新建或返回列表前，未保存的详情须先原子保留为可明确恢复的浏览器草稿；该草稿只属于详情，不把独立快速输入／列表请求一并归档或在恢复时覆盖它们，归档与导航间的崩溃窗口仍保留完整页面副本；保留失败停留当前编辑器，不改写主机。存在结果未知的请求时不允许通过切换清掉请求。编辑区内 Ctrl／⌘S 执行同一显式保存，不在输入法组字时提交。

默认列出未完成，每页 100 条，支持状态筛选和标题/详情字面搜索；游标绑定库身份及筛选条件。JSON 导出全部状态的当前业务记录，公开格式 corilo-todos-v1，最多 10000 条/8 MiB，超限明确失败；不含幂等回执、凭据和会话，不等价于完整数据库备份。SQLite 专用目录在 Markdown 外，备份需要停写并包含整个目录，笔记现有 notes/state 备份不会自动包含待办。

一次性内部日程、提醒及 ICS 导出后续实现；周期规则和外部日历双向同步后置。创建待办不自动创建提醒，日程结束不自动完成待办。

提醒保存确定时刻、时区和通知渠道。歧义时间及夏令时冲突需澄清；渠道未启用只能保存事项，不能回执“已安排通知”。持久调度负责重启恢复、发送竞争、取消与未知投递，不用模型记忆或浏览器/内存定时器代替。主机离线期间无法投递，恢复后的补发策略须明确，不盲目重发。提醒渠道尚未选定，未经授权不发送邮件或他人日历邀请。

## 5. 记忆

后续支持明确“记住、更正、忘掉”，保存内容、来源、时间和版本，用户可直接查看修改。用户陈述不冒充外部核实，推断与已确认内容区分。自动提取策略尚未决定，不默认无限留存或逐条强制审批。

忘掉记忆需停止其检索和自动注入，并区分原始笔记/会话是否仍保留；不承诺删除模型供应商已接收内容或用户备份。遗忘记录与旧包恢复的语义须随记忆功能一起设计和验收。

## 6. 数据自主与备份

正文和附件可直接阅读；事项与记忆提供版本化公开格式，完整资料包最终包含对话、关联与偏好，并明确排除凭据及内部诊断。局部知识库 ZIP 不能称完整账号备份。导入先校验，不能默认覆盖已有资料、执行历史工具或发送旧提醒。

本地版本历史与独立备份分别建设。笔记级备份采用成熟工具，在停服且停止外部编辑后同时保存正文、附件与独立历史状态；恢复到全新位置，先校验历史完整性和原知识库绑定，再生成新实例配置，不覆盖原库。该范围不含 Harness 会话/凭据或浏览器草稿，不称完整实例备份。NAS 备份需协调文件、会话和业务数据的一致性，并实际恢复比对。备份/保留周期尚未确定；拥有 NAS 不等于已完成备份交付。GitHub 不是使用或同步前提。

## 8. 待决定项

具体 Linux 发行版、常开主机/NAS 型号、远程认证/网络方式、通知渠道、自动记忆范围、备份与会话保留期、日程/提醒的具体存储与调度实现尚未决定；待办已采用本机 SQLite。实现可选简单可迁移的本地存储，不要求沿用旧云端 PostgreSQL，但必须区分方案建议和实际实现。不得因底座切换自动迁移或删除现有用户数据。
