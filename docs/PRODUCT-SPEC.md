# Corilo 可里业务规格

v0.32 · 2026-11-10。本文件是当前产品规则唯一来源。用户决定采用 DeepSeek Harness 主体加笔记、日程插件，近期优先个人自部署。旧云端邀请版规则保留在 [v0.16 历史归档](history/PRODUCT-SPEC-v0.16.md)，不覆盖本规格。未实现功能均是目标，不是已交付承诺。

当前优先级已收敛为核心笔记/待办与良好体验，暂缓截止日期、笔记联动、日程、提醒与自动记忆。笔记明确移除草稿库、历史、回收站和手动模式；待办导出保留为次级入口。以下未来目标不能作为当前追加功能的授权。

## 1. 产品与部署范围

首期单用户，服务和资料由用户自己的常开设备承载；浏览器跨设备访问同一服务，不要求手机运行 Agent。Harness 提供对话、模型设置、会话及默认工具，Corilo 通过公开插件接口扩展。初期 DeepSeek，不另造模型管理、Agent loop 或权限审批框架。

工作资料保存在主机本机磁盘；NAS 先承担备份。不能将未经验证的网络共享、客户端双向同步、休眠主机宣称为可靠全天服务。公网暴露前必须实际验证身份、来源和网络边界；个人模式不是无鉴权远程公开服务。首个目标为 Linux 小主机/常开电脑；具体硬件、发行版及远程访问方式尚未选定。

长期运行复用系统服务管理，固定持久 Harness home、共享 Agent 配置根、工作目录和端口。检查时报告解析位置，凭据/会话目录不得与笔记或恢复状态重叠。进程重启不自动重发捕获或覆盖草稿；机器开机、用户登录、自启与休眠恢复须分别验收。

## 2. 笔记与文件

笔记只提供新建、查找、读取、编辑、同目录改名和自动保存。正文是普通 UTF-8 Markdown，附件保持原格式；主机文件是唯一权威。配置、凭据、会话和待办数据库在笔记目录外。

默认新建立即创建正式空 Markdown，选择未占用的“未命名.md”“未命名 2.md”等名称，最多检查 1000 个候选；初始页面直接输入也可自动创建。创建／保存逐字保留传入文本。浏览与正文搜索有界且无模型调用，按已知相对路径打开不依赖列表扫描成功。

正文使用 CodeMirror 6 和 Lezer，提供即时 Markdown 样式、常用格式、列表续写、查找与撤销／重做；完整阅读预览复用 markdown-it／DOMPurify，仅主动打开时渲染并限流，禁用原始 HTML、危险链接及主动图片／外部资源。编辑会话用独立标识隔离，打开另一篇重置撤销，首次创建回执／同一篇改名保留光标和撤销历史。

自动保存只有一种模式，Ctrl／⌘S 表示立即保存。提交中可继续输入，回执只确认提交快照，不覆盖后续输入；组字期间暂停提交。正常新建或切换前先保存当前修改，失败停留原内容。状态轻量显示，只有主机确认才显示已保存。错误、冲突及未知结果暂停自动写入；未知结果先只读核对，不自动重发创建，只有正文一致才能直接确认。冲突可查看文件内容、明确采用文件内容或保存副本；采用不同内容前确认放弃当前输入。

不提供笔记草稿库、恢复草稿、版本历史、回收站或删除页面，不访问笔记 IndexedDB、不自动运行 Git。输入仅在当前插件会话内保留，切换宿主面板可继续保存；未保存／未知结果关闭页面时提醒。整页刷新、崩溃或关闭后不承诺恢复输入。旧浏览器草稿及历史目录不读取、迁移或删除；旧版本资料恢复工具仅为存量兼容，不是当前产品功能。

新配置只需 Markdown root，不需要 stateRoot 或 Git。旧 stateRoot 配置可兼容启动，插件不读写该目录。重命名仍检查读取版本且拒绝同名覆盖，不改写笔记链接或待办关联；结果未知需只读核对新旧文件后选择。更新须提供实际读取的 SHA-256 版本，陈旧版本拒绝覆盖；拒绝路径穿越、隐藏路径、软／硬链接和特殊文件。服务只串行自己的操作，不保证对外部编辑器或 Harness 默认文件／bash 工具的跨进程事务。

## 3. 对话与结果

沿用 Harness 原生会话、工具进度、停止和恢复能力。关闭网页不是停止，重连不自动重发原请求。旧 Pi 会话不自动导入为 Harness 可执行会话；任何历史导入不得执行旧工具。

模型承诺不能代替实际文件或结构化记录成功。结果与失败应可查询，实际修改保留；不承诺停止时自动回滚。工具接入不等于完整笔记界面已完成，桌面检查不等于手机验收。

## 4. 个人事项与提醒

用户待办 todo、日程 event、提醒 reminder 与 Agent 执行任务是不同概念。Harness 内部执行计划或工具 todo 不自动成为个人事项。Corilo 事项插件提供同一业务服务的直接 UI 操作与 Agent 工具。

当前个人待办仅有标题、说明、未完成／已完成状态，支持完成／撤销。标题去掉首尾空白后 1–200 字符，说明最多 20000 字符，拒绝无效 Unicode。不提供删除、取消、笔记关联、草稿库、恢复、手动保存开关或详细新建表单。

页面和工具共用 coreTodos 业务边界与 SQLite 服务，修改／完成／撤销检查读取时的整数版本。持久请求 UUID 与变更在同一事务提交；相同 UUID／内容重试返回原提交结果，异内容拒绝，不能重复新建。版本冲突保留当前输入供核对；结果未知保留原请求，只有用户明确重试才发送同一 UUID。旧页面遇到资料库身份改变时暂停写入。

快速录入只填标题、回车连续新增。列表直接完成／撤销，不能覆盖其他事项的未保存输入。搜索与未完成／已完成／全部筛选常显；从已完成新增后回到未完成，从全部新增保持全部，新增成功清除搜索，让新事项可见。列表 N、/、上下键及 Enter 用于录入／查找／导航，不拦截文本输入或组字。

桌面详情在侧栏、手机在独立视图打开，只有标题和说明。离开编辑区、切换事项或返回列表时先保存修改，成功才继续目标操作；首次点击不能因 blur 并发被吞掉。Ctrl／⌘S 立即保存，Esc 保存后返回。组字期间不提交，失败／冲突停留当前输入，未知结果禁止自动重发或通过切换清掉原请求。正常界面没有保存按钮，异常可明确重试。

输入只在当前插件会话内保留，未保存／未知请求关闭页面时提醒，不承诺刷新、崩溃恢复。不访问待办 IndexedDB；旧浏览器草稿保留但不读写或清除。旧 SQLite 取消记录和关联字段不迁移、不删除、不转换；当前页面和工具不展示或修改这些能力，导出仍包含原记录及字段。

默认列出未完成，每页 100 条，支持标题／说明字面搜索；游标绑定库身份、筛选及当前记录范围，旧取消记录在 SQL 分页前排除。JSON 导出完整旧版 corilo-todos-v1 业务格式，包括旧取消记录和关联字段，最多 10000 条／8 MiB，超限明确失败；不含幂等回执、凭据和会话，不等价于数据库备份。SQLite 专用目录在 Markdown 外，备份需要停写并包含整个目录。

一次性内部日程、提醒及 ICS 导出后续实现；周期规则和外部日历双向同步后置。创建待办不自动创建提醒，日程结束不自动完成待办。

提醒保存确定时刻、时区和通知渠道。歧义时间及夏令时冲突需澄清；渠道未启用只能保存事项，不能回执“已安排通知”。持久调度负责重启恢复、发送竞争、取消与未知投递，不用模型记忆或浏览器/内存定时器代替。主机离线期间无法投递，恢复后的补发策略须明确，不盲目重发。提醒渠道尚未选定，未经授权不发送邮件或他人日历邀请。

## 5. 记忆

后续支持明确“记住、更正、忘掉”，保存内容、来源、时间和版本，用户可直接查看修改。用户陈述不冒充外部核实，推断与已确认内容区分。自动提取策略尚未决定，不默认无限留存或逐条强制审批。

忘掉记忆需停止其检索和自动注入，并区分原始笔记/会话是否仍保留；不承诺删除模型供应商已接收内容或用户备份。遗忘记录与旧包恢复的语义须随记忆功能一起设计和验收。

## 6. 数据自主与备份

正文和附件可直接阅读；事项与记忆提供版本化公开格式，完整资料包最终包含对话、关联与偏好，并明确排除凭据及内部诊断。局部知识库 ZIP 不能称完整账号备份。导入先校验，不能默认覆盖已有资料、执行历史工具或发送旧提醒。

笔记是普通目录，可使用用户已有备份工具。当前插件不建设版本历史、回收站或自动备份流程；旧版离线恢复工具保留用于已有资料。待办 SQLite、Harness 配置／会话的完整实例备份仍需分别规划、停写并实际恢复验证。NAS 先作备份方向，未经验证不作为网络工作盘；GitHub 不是使用前提。

## 8. 待决定项

具体 Linux 发行版、常开主机/NAS 型号、远程认证/网络方式、通知渠道、自动记忆范围、备份与会话保留期、日程/提醒的具体存储与调度实现尚未决定；待办已采用本机 SQLite。实现可选简单可迁移的本地存储，不要求沿用旧云端 PostgreSQL，但必须区分方案建议和实际实现。不得因底座切换自动迁移或删除现有用户数据。
