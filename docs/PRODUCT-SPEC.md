# Corilo 可里业务规格

v0.12 · 2026-10-09。本文件是当前业务规则唯一来源；下列验收均待正式实现验证。

## 1. 知识库与文件

首期一个活动知识库，正文为普通 Markdown，附件为普通文件。目录是组织方式，不强制新增全库身份数据库或专有内容格式。已有未知属性和非应用生成的内容应保留。敏感配置、模型密钥、Git 凭据、Pi 会话、缓存和运行日志存放在知识库之外。

本地可独立使用；尚未绑定 GitHub 时不阻止编辑。文件管理复用 Files.md 的操作习惯。自动保存成功后显示“已保存到本机”，上传状态另行显示。保存失败保留编辑中的文本并给出重试入口，不能宣称成功。

同一设备避免编辑器与 Agent 同时修改同一文件：Agent 运行前先保存已编辑内容，运行期间编辑器可阅读，编辑入口暂停并提供停止 Agent 后编辑的入口。结束后重读文件。外部程序修改造成差异时保留当前草稿并让用户重新加载或另存，不静默覆盖；不承诺拦截任意外部程序写入。

## 2. 对话与 Agent

用户发出请求后由 Pi 运行。明确的阅读、创建、追加、修改、移动请求可直接执行；不要求逐文件审批。Agent 自行判断分类、目录和步骤；确实缺少目标或存在互斥解释才提问。无操作意图的讨论不自动生成永久笔记或任务。

系统提示词说明知识库目录和组织约定、优先保持已有结构、避免无关修改、准确报告实际操作。工具、保存保护、模型认证和选择沿用 Pi 默认能力，不增加自定义 propose/apply 工具链。Pi cwd 不构成文件系统沙箱。

对话展示回复与必要的工具进度，文件结果卡来自真实工具结果及文件状态，不凭模型文字伪造“已保存”。停止只中断后续执行，已经完成的文件修改仍保留。失败时说明已完成和未完成部分，不宣称自动回滚。

“仅保存原话”直接保存为独立 Markdown，并返回打开入口，不调用模型。会话在本机保留，可新建、切换和继续；首期不把 Pi 会话文件同步到知识库仓库，不恢复另一台设备上的活动执行。

## 3. GitHub 绑定

使用用户已有的私有 GitHub 仓库作为知识库远端，独立于 Corilo 代码仓库。首期通过设置填写仓库地址并使用本机凭据存储；采用仅授予该仓库所需读写权限的凭据。界面不得把密钥写进 Git remote URL、日志或知识库。

新设备克隆到新的空目录。现有本地库与非空远端不自动混合：先下载到独立目录，再由用户选择使用哪个库或明确导入。绑定时核对远端身份和私有属性；验证失败不能显示已连接。退出绑定只停止同步，保留本地文件，不删除远端。

## 4. 同步语义

本地保存不等待网络。保存静止后合并提交，Agent 一轮结束后统一提交；同步任务与本机 Agent 执行互斥，运行中只显示待同步。触发点为启动、回到前台、保存批次完成和手动“立即同步”。不承诺移动端持续后台同步。

每次同步先保存并提交本地变更，再 fetch、合并、push。重试使用 Git 当前状态，不重建自定义 ACK、tombstone 或同步数据库。不 force-push。没有确认远端接受当前提交之前，不显示“已同步”。掉线、权限错误和远端变化均保留本地文件及提交。

无冲突变更自动合并。同一文件冲突、删除与修改冲突、二进制冲突均暂停本轮发布，保留双方版本并提示处理。不将带 Git 冲突标记的文件直接交给正常编辑器或 Agent；在隔离合并目录内处理。用户可选本机、远端、保留两份，或编辑合并结果，再继续同步。两份模式生成不覆盖既有文件的名称。

Git 历史用于查找和恢复旧版本；删除或恢复仍是普通新提交。撤销本机尚未上传的动作与撤销已同步修改必须区分，不改写已公开到知识库远端的历史。Git 不是无限附件网盘；远端大小限制导致失败时显示具体文件并保留本地资料。

## 5. 安装与隐私

桌面安装启动器后点击 Corilo，自动启动本地服务并打开 Chrome；日常使用无需运行命令。Android 安装一个 APK，首启自动初始化运行环境，再进入相同产品页面。初始化、升级和故障恢复需有进度与可重试错误，不以空白页代替状态。

本地 HTTP 服务只监听 loopback，限制可信来源并校验会话，防止其他网页调用本机文件工具。平台凭据尽量使用系统安全存储；缺乏可用集成时必须明确配置保存位置及访问限制。该保护不替代 Pi 自身工具行为。

首次配置说明在线模型会接收当前对话及工具读取的相关资料，私有 GitHub 仓库由托管商保存数据，首期没有端到端加密。密钥不进入知识库。无需每次读取或修改都再次确认。
