# Corilo 可里产品

v0.33 · 2026-11-11。Corilo 是运行在个人 Linux 小主机／常开电脑上的文件工作区，浏览器可以从手机和其他电脑访问。用户保存资料、查找和编辑笔记、记录清单与日记，也能在 Harness 原生会话中请 Agent 操作同一份资料。

当前采用 DeepSeek Harness 主体加 Files.md 工作区插件。完整移植 Files.md 前端及交互，先保留其菜单和功能，后续再按实际使用决定裁剪。普通记录、编辑、勾选不需要模型；用户明确请求 Agent 时才使用模型。模型、会话、鉴权、权限和运行机制沿用 Harness，不另造模型管理、机器人服务或 Agent loop。

正文、待办和日记采用普通 Markdown，附件保持原格式。目标是一个插件、一个工作区、一套资料，避免让用户在独立笔记和待办界面间切换。旧 SQLite 待办通过显式迁移进入清单；原记录和数据库保留，不能把界面整合等同于数据迁移完成。

主机本机磁盘作为工作目录，NAS 先作备份。无需官方账号、Supabase 或 GitHub 绑定。首期不做公共注册、多租户计费或重新建设跨设备同步；不同浏览器直接连接同一服务。Files.md 的 Go 同步和 Telegram 机器人不在当前运行链路中，对应资料操作交由 Harness Agent。

日期、可靠提醒、自动记忆、真实设备部署和完整实例备份仍是后续工作；Files.md 菜单存在不代表外部渠道、通知或硬件能力已经启用。业务规则以 [PRODUCT-SPEC.md](PRODUCT-SPEC.md) 为准。
