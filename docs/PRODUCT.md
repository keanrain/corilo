# Corilo 可里产品设计

v0.32 · 2026-11-10。个人自部署，DeepSeek Harness 为应用主体，Corilo 为笔记和行动插件。规则以 [业务规格](PRODUCT-SPEC.md) 为准，技术与证据见 [技术设计](TECHNICAL_DESIGN.md)。

当前优先核心笔记和待办：快速记录、查找、阅读编辑，以及新增、查看、完成/撤销个人待办。 用户明确要求整体体验像成熟软件：正常记录不拆成多步提交表单；笔记直接写、标题内修改，待办回车新增、勾选完成，详情按需打开并在离开时保存。保存反馈安静、辅助能力次级、异常仍可发现，是本轮取舍。输入可靠保留、手机操作顺手和首次启动简单，是本阶段的主要价值。日程、提醒、笔记联动和自动记忆暂缓。长期目标仍是帮助个人记住资料、结合背景思考并逐步行动。用户不用先设计目录、数据库或工作流；资料以普通文件和公开格式保存在自己设备，离开应用也能阅读和带走。

Harness 提供网页、对话、会话、模型设置、默认工具和执行机制。Corilo 增加笔记的直接编辑与 Agent 能力，再增加个人事项与记忆。首期默认在线模型 DeepSeek，不需要本地模型或手机运行 Agent，不重写一套 Harness 或叠加 Pi 运行主链路。

首个部署目标已选为 Linux 小主机/常开电脑。运行服务的电脑/小主机保持开机，手机和其他电脑通过浏览器访问同一工作目录；NAS 先做备份，不直接作为未经验证的网络工作盘。NAS 全部运行、具体桌面系统、远程鉴权与手机浏览器仍须部署验收。首期不做公共注册、多租户计费、原生 APK、团队协作或完整离线同步。

当前笔记使用独立插件，只有新建、查找、编辑／改名与自动保存，正文复用 CodeMirror 6。用户明确认为草稿、历史、回收站冗余，已从当前产品移除；失败保留当前输入并提示，未保存关闭时提醒，旧资料不删除。待办只保留新增、查找、编辑、完成／撤销及导出，不提供草稿库、手动模式、关联或取消功能；日历、可靠提醒、自动记忆、实际设备部署与完整实例备份尚未交付。旧 Files.md／Pi 等历史实现保持原位置，不作为当前路线扩展。
