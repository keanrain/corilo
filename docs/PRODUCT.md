# Corilo 可里产品设计

v0.18 · 2026-11-08。个人自部署，DeepSeek Harness 为应用主体，Corilo 为笔记和行动插件。规则以 [业务规格](PRODUCT-SPEC.md) 为准，技术与证据见 [技术设计](TECHNICAL_DESIGN.md)。

帮助个人记住资料、结合背景思考，并逐步形成待办、日程与可靠提醒。用户不用先设计目录、数据库或工作流；资料以普通文件和公开格式保存在自己设备，离开应用也能阅读和带走。

Harness 提供网页、对话、会话、模型设置、默认工具和执行机制。Corilo 增加笔记的直接编辑/原话保存与 Agent 能力，再增加个人事项与记忆。首期默认在线模型 DeepSeek，不需要本地模型或手机运行 Agent，不重写一套 Harness 或叠加 Pi 运行主链路。

运行服务的电脑/小主机保持开机，手机和其他电脑通过浏览器访问同一工作目录；NAS 先做备份，不直接作为未经验证的网络工作盘。NAS 全部运行、具体桌面系统、远程鉴权与手机浏览器仍须部署验收。首期不做公共注册、多租户计费、原生 APK、团队协作或完整离线同步。

当前已实现独立笔记插件的文件服务、工具及 Harness 内笔记页面，补齐浏览器持久草稿、本机历史/回收站和独立分发，桌面 Chromium 流程已验证；真实手机、日程插件、可靠提醒、长期记忆、一体化安装与完整备份恢复按阶段交付。已有 Files.md/Pi 本机和云端代码保留，作为迁移前实现；其通过记录不自动属于 Harness。
