# Corilo 可里产品说明

**简体中文** | [English](PRODUCT.en.md)

2026-11-15。当前产品由三个可独立维护、安装和分发的 DSH 插件组成。产品规则见 [业务规格](PRODUCT-SPEC.md)，命令见 [开发指南](DEVELOPMENT.md)。

| 产品 | 当前版本 | 用途 |
|---|---|---|
| notes | 0.7.0 | Files.md 笔记、文件、收集、日记和 Markdown 清单 |
| todos | 0.6.4 | 任务、日期与截止、日历、任务时间块和持久站内提醒 |
| 学习导师 | 0.1.0 | 学习路线、诊断、互动练习、考官核验和间隔复习 |

源码启动器为新实例配置 notes＋todos planner。学习导师仅供已有 DSH 用户另行安装，不进入默认组合；安装后自行选择工作区与教学预设。三个插件复用 DSH 的认证、会话、模型与权限。

## 当前体验

笔记和任务的日常操作不需要模型。笔记正文与附件保存在主机普通文件中；正式任务与日历保存在 todos 的 SQLite 数据库。Markdown 勾选清单仍是文档内容，不自动与任务数据库同步。

planner 提供六个任务视图、搜索与分页、计划日期、截止、优先级和清单。日历提供月／周／日／议程视图、独立事件、全天事件和任务时间块。站内提醒持久保存；网页通知需要主动授权，关闭页面不推送。

学习导师在会话工作区保存 `.learn/` 学习记录，使用 DSH 原生会话和互动界面。功能与安装说明见 [导师指南](../packages/learn-anything/README.md)。

## 支持与未实现范围

运行环境固定为 DSH 0.2.2-rc.3、Node.js ≥24.9.0。首个部署方向是 Linux 常开主机与浏览器；真实手机、NAS 和目标部署不能由本地测试推定为已验收。

已有 notes 单插件与 todos v1 配置继续保留。planner v2 需要新目录，尚无 v1 升级工具，不自动修改旧配置或迁移数据。

重复任务、笔记来源关联、CalDAV／ICS、邮件与其他外部通知尚未实现。笔记备份不等于整实例备份，todos 与导师数据需另行纳入备份范围。

原 v0.34 的长期规划保存在 [历史产品方案](history/v0.34/PRODUCT.md)，不作为当前交付承诺。已执行验证与限制见 [交接记录](HANDOFF.md)。
