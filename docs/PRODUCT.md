# Corilo 可里产品设计

v0.12 · 2026-10-09

## 定位

个人使用的本地 Markdown 知识库与 Agent 助手。用户可以像使用 Files.md 一样直接查看、编辑和查找文件，也可以在对话中让 Agent 阅读、整理、追加或改写资料。文件保存在自己的设备，GitHub 私有仓库承担远程备份与多端同步。

核心体验是“说清目的，Agent 完成文件操作，再打开结果继续编辑”。用户不必先选分类、目标目录和处理模式；有明确意图时由 Agent 决定，只有影响结果的歧义才询问。

## 首期范围

| 能力 | 首期选择 |
|---|---|
| 笔记 | 复用完整 Files.md 文件浏览、Markdown 编辑、查找和现有 checklist/Later 体验 |
| 对话 | 流式回复、停止、继续本机会话、真实文件结果卡片 |
| Agent | Pi 默认文件和 shell 工具、会话与模型配置；初始引导 DeepSeek |
| 同步 | 一个 GitHub 私有知识库仓库，每台设备一份本地 Git 工作树 |
| 桌面 | Windows 11 x64、macOS 14+ Apple Silicon 优先，Chrome 页面与自动启动器 |
| 手机 | Android 15/16/17 ARM64，集成 APK；Android 17 为主要验收目标 |
| 离线 | 本地浏览、编辑、搜索和待同步保存；在线 AI 需要网络 |

平台版本是计划支持范围，不是当前测试结果。Windows ARM、Intel Mac、旧 Android 和 iOS 后置。

## 使用情景

1. 临时想法：输入后让 Agent 保存到合适位置；也可以点“仅保存原话”，直接生成 Markdown，不调用模型。
2. 基于资料提问：Agent 阅读知识库并回答，涉及文件的回答可打开对应原文；普通讨论不自动保存为新笔记。
3. 整理知识：用户说“把这些记录整理进项目笔记”，Agent 使用默认工具执行，回报实际修改并提供文件入口。
4. 跨设备接续：桌面保存后同步，手机打开时拉取；文件继续使用，但正在运行的 Agent 和对话执行状态不跨端迁移。

## 明确取舍

不建设独立账号体系、云端 Agent、Supabase 同步服务或本地模型引擎。首期不新增 Today、日历、系统提醒、支付、邮件或后台自主任务循环。保留上游基础能力不意味着继承其 Bot 和服务端调度。

不为 Pi 再做一套权限、逐文件确认、事务保存或模型管理框架。默认工具的限制照实呈现，系统提示词是行为约定，不是安全隔离。数据保护依靠基本编辑反馈、Git 历史、同步冲突保留和用户可见的失败状态。

GitHub 私有仓库控制访问但不提供端到端加密。使用在线模型时，Agent 读取并用于请求的资料会发往模型服务商。首期通过用户发起对话控制使用，不追加逐段授权流程。

业务细则和验收统一见 [PRODUCT-SPEC](PRODUCT-SPEC.md)。
