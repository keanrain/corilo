## 4. 本轮收敛了什么

从“从零建设一个泛化个人操作系统”，收敛到“复用轻量文件工作区，补齐受控文字助手和小型行动层”。先验证现有页面与编辑体验，不为了 React、TypeScript 或新后端而全面重写。原始 JavaScript 可保留，新模块可渐进使用 TypeScript。

明确分开普通讨论、快速记录、知识写回与正式任务。不把每条聊天自动写成复选项，不把一段没有行动含义的想法变成待办，不靠清空 Inbox 衡量价值。

任务只先解决状态、计划、截止、一次提醒与来源。保留 Today；日历网格、系统日历联动、重复任务、自动排程不因参考项目已有相关入口就自动进入 M0。

轻量不意味着省略数据保护：统一写入、版本核对、修改前内容、本地恢复、同步冲突和准确回执继续保留。
