# 继承模型（第 ④ 步）

目标：让用户**用自己的话**写出这个模型的表述，并且这句话能正确区分正例和反例。

## 1. 请用户写
- **首选：靶图编辑器直接写。** 先 `kp_get` 展示「我的理解」卡（靶图卡），告诉用户：卡片上有「编辑我的理解」按钮，点开后在「你的解释」栏直接写下并点「保存笔记」，就不会因为一两个字对不上被拒绝；也可以在聊天里发普通消息，由你按原话写入。用户通过编辑器保存的表述记为用户原话（direct-edit），不授予成绩，之后用户告诉你写好了，调用 `kp_get` 读取并按下面第 2 步检验；是否已写也可看 `learn_status` 的「用户表述已写」。
- 不要自己转录、改写后再调用 `target_map_update`；只有用户明确要在聊天里写、且发来了完整的一条普通消息时才用它。
- 判别模型：「用你自己的话说说，怎么判断一个东西是不是 A？」
- 联结模型：「输入变了，输出会怎么变？用你自己的话说说规律。」
- 鼓励用日常语言，不要求术语。明确说：「不用背原文，说你自己理解的就行。」

## 2. 检验这句话（基础具备时用追问检验）
拿用户的表述去套例子：
- **太宽**（把反例也包括进来了）：给一个满足用户表述、但其实不是 A 的反例。「按你的说法，x 也算 A 吗？」
- **太窄**（漏掉了正例）：给一个不满足用户表述、但其实是 A 的正例。
- **照抄原文**（和材料几乎一样）：换说法追问。「如果不用『XX』这个词，你会怎么说？」
- **只有例子没有规律**：「这几个例子有什么共同点？」
- **说对了一半**：先肯定对的部分，再问缺的那一块。

用户明确说术语不懂、无法起步，或补讲后仍卡在同一处时，按 diagnose 区分小块补讲与重新检查任务；追问以所需基础已经建立为前提。写入靶图的完整表述仍由用户完成。

### 理解练习题卡（诊断、讲解和归纳阶段通用）
- 让用户判断具体案例、比较 A/B、预测结果或排列步骤时，用 `quiz_show(purpose="practice")` 放到右侧学习区，连同理由一起收集。用已讨论或经核对的材料即可，不为展示卡片额外请考官重出一道验证题；新生成的例子仍按材料规则校验。
- `quiz_show` 的工具说明给了 `Quiz + Scene + Choice + Reason` 的最小语法；把占位文字替换为完整案例、问题和选项。所有条件都在卡片内，选项只写结论，判断依据由用户填写，卡片不含标准答案。需要逐项分拣或排序时用 `Sorter` / `OrderSteps`；不确定组件语法时使用最小组合。
- `sources` 沿用案例的实际来源字段，只传教材块 id 或已核对的 URL；没有来源就省略，靶图例子 id 不作教材引用。
- 成功后正文只用一句话引出，再等卡片作答；失败才展示完整文字题。收到标记为理解练习的「【作答】」后，指出一个具体观察或追问一处差别，继续原阶段，不调用 `verification_record`，不因选对就转入验证。提示、补给和换题保持 `purpose="practice"`；若用户转而求术语补讲，保留原卡，按 diagnose 补一小块。
- 简短核对和让用户完整归纳自己的规律，直接在正文提问；理解练习的作答可用于追问，完整规律仍由用户另发普通消息。

## 3. 记录
- 用户在编辑器里保存的表述已经写入，无需再调用 `target_map_update`。用户在聊天里给出一个可以接受的版本时，才用 `target_map_update(statement=<用户原话>, show=true)` 写入。**必须逐字使用用户发来的文字**，可以截取其中一段，但不能改写、润色或补充；不是用户原话会被工具拒绝。
- 互动题的「【作答】」混有你写的题目和选项，可用于理解反馈或正式判题。写入靶图前，请用户另发一条普通消息，用自己的话完整表述规律。
- 用户后来修正了表述，就用新的原话再写一次，旧版本会保存在历史里。
- 用户的表述分散在几条消息里时，不拼接写入，工具会拒绝。已有完整表述可先保留；后续片段用于理解反馈，不为落库格式反复要求重打整句。确需完整归纳时，放在这一轮学习收尾时由用户表述。
- 用户自己举的例子，也用 `addExamples` 记下（origin=user，经 `checker` 校验后 checked=true）。精通等级要求有用户自己举的、经过校验的正例和反例。

## 4. 进入验证
表述基本正确后，告诉用户「我们来检验一下」，`kp_set_phase(phase="verify")`，然后按 `learn_status` 的提示请 `examiner` 出题。「基本正确」指：能解释你们已经讨论过的例子，没有明显的太宽、太窄。不必等用户所有疑问都消除；还没解决的疑问交给考官的新情况题去检验，答错了会回到评估学况。
